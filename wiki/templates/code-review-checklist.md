# Code Review 检查清单

## 1. 代码质量

### 1.1 可读性
- [ ] 代码清晰易懂，无需过多注释
- [ ] 变量和函数命名符合规范
- [ ] 代码格式统一（缩进、换行）
- [ ] 复杂逻辑有必要的注释

### 1.2 设计
- [ ] 代码结构合理，职责清晰
- [ ] 无重复代码（DRY 原则）
- [ ] 抽象层次适当
- [ ] 符合 SOLID 原则

### 1.3 性能
- [ ] 无明显性能问题
- [ ] 数据库查询已优化（无 N+1 问题）
- [ ] 合理使用缓存
- [ ] 大数据量处理使用批处理

---

## 2. SQL 代码检查

### 2.1 DDL 语句
- [ ] 所有 `NUMBER` 类型都指定了精度和标度
- [ ] `VARCHAR2` 已改为 `VARCHAR`
- [ ] `CLOB/BLOB` 类型转换正确
- [ ] 索引定义合理
- [ ] 约束定义完整（主键、外键、唯一约束）

### 2.2 DML 语句
- [ ] 使用参数化查询（防止 SQL 注入）
- [ ] JOIN 使用 ANSI 标准语法（不使用 `(+)`）
- [ ] 聚合查询性能合理
- [ ] 避免使用 `SELECT *`

### 2.3 存储过程
- [ ] 异常处理完善
- [ ] 事务管理正确
- [ ] 游标使用合理（避免性能问题）
- [ ] 参数验证充分

---

## 3. Java 代码检查

### 3.1 JDBC 使用
- [ ] 正确使用连接池
- [ ] PreparedStatement 防止 SQL 注入
- [ ] 资源正确关闭（try-with-resources）
- [ ] 异常处理完善

### 3.2 业务逻辑
- [ ] 边界条件处理正确
- [ ] 空值检查充分
- [ ] 并发安全
- [ ] 事务管理正确

## 4. 测试

### 4.1 单元测试

### 4.2 集成测试
- [ ] 关键业务流程有集成测试
- [ ] 测试数据准备充分
