## 4. 重要技术突破

### 4.1 数据类型映射精通

**掌握要点：**
```sql
-- NUMBER 类型必须指定精度
NUMBER(p, s) → NUMBER(p, s)  ✅
NUMBER       → NUMBER(38, 0) ❌ 默认会丢失小数

-- 字符串类型
VARCHAR2(n)  → VARCHAR(n)
CLOB         → VARCHAR(16777216)

-- 日期类型
DATE         → DATE
TIMESTAMP    → TIMESTAMP_NTZ
```

**避免陷阱：**
- ⚠️ 始终明确 NUMBER 精度
- ⚠️ CLOB 大小限制
- ⚠️ 时区处理

---

### 4.2 存储过程转换技巧

**核心变化：**
```sql
-- OUT 参数 → RETURNS
Oracle:    p_salary OUT NUMBER
Snowflake: RETURNS NUMBER

-- 变量引用加冒号
Oracle:    SELECT ... INTO v_var
Snowflake: SELECT ... INTO :v_var

-- ELSIF → ELSEIF
Oracle:    ELSIF condition THEN
Snowflake: ELSEIF (condition) THEN

-- 异常类型
Oracle:    NO_DATA_FOUND
Snowflake: STATEMENT_ERROR
```

---

### 4.3 性能优化方法论

**优化工具箱：**

1. **聚簇键（Clustering Key）**
   ```sql
   ALTER TABLE large_table CLUSTER BY (frequently_filtered_column);
   ```
   - 适用：大表（>1TB）
   - 效果：3-5 倍性能提升

2. **物化视图（Materialized View）**
   ```sql
   CREATE MATERIALIZED VIEW summary AS
   SELECT ... complex aggregation ...
   ```
   - 适用：复杂聚合查询
   - 效果：10 倍以上性能提升

3. **Search Optimization Service**
   ```sql
   ALTER TABLE customers ADD SEARCH OPTIMIZATION;
   ```
   - 适用：点查询、模糊查询
   - 效果：100 倍性能提升

4. **Warehouse 大小选择**
   - 根据查询复杂度选择
   - 使用 Auto-Suspend 节省成本

## 7. 核心知识速查卡

### 7.1 数据类型映射

```
NUMBER(p,s) → NUMBER(p,s)  ✅ 保持一致
VARCHAR2(n) → VARCHAR(n)    ✅ 去掉 2
CLOB        → VARCHAR(16777216) ✅ 最大 16MB
DATE        → DATE          ✅ 兼容
TIMESTAMP   → TIMESTAMP_NTZ ✅ 默认无时区
```

### 7.2 SQL 语法差异

```sql
-- DUAL 表
Oracle:    FROM DUAL
Snowflake: 可省略

-- OUTER JOIN
Oracle:    WHERE a.id = b.id(+)  ❌ 不支持
Snowflake: LEFT JOIN ... ON     ✅ ANSI 语法

-- 分页
Oracle:    WHERE ROWNUM <= 10   ❌ 不支持
Snowflake: LIMIT 10             ✅

-- 日期函数
Oracle:    SYSDATE
Snowflake: CURRENT_TIMESTAMP()  ✅ 需要括号
```

### 7.3 存储过程转换

```sql
-- 参数
Oracle:    p_var OUT NUMBER
Snowflake: RETURNS NUMBER       ✅

-- 变量引用
Oracle:    INTO v_var
Snowflake: INTO :v_var          ✅ 加冒号

-- 条件
Oracle:    ELSIF
Snowflake: ELSEIF               ✅ 拼写不同

-- 异常
Oracle:    NO_DATA_FOUND
Snowflake: STATEMENT_ERROR      ✅
```

### 7.4 性能优化

```sql
-- 聚簇键（大表 >1TB）
ALTER TABLE orders CLUSTER BY (order_date);

-- 物化视图（复杂聚合）
CREATE MATERIALIZED VIEW summary AS ...

-- Search Optimization（点查询）
ALTER TABLE customers ADD SEARCH OPTIMIZATION;

-- Warehouse 大小
Small    → 简单查询
Medium   → 日常 ETL
Large    → 复杂聚合
X-Large  → 大数据 JOIN
```
